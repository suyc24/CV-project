# 2D / Hybrid Benchmark Sessions

These sessions were recorded before the dedicated 3D-only benchmark pass. They are still useful as regression tests for the original 2D fingertip-motion detector and the conservative hybrid depth-assist mode.

- `bench_adjacent_boundary`: adjacent-key boundary behavior.
- `bench_depth_contact`: Record3D contact/depth behavior.
- `bench_idle_hover`: hovering / idle hand behavior.
- `bench_multi_finger_rest_then_tap`: multiple fingers resting, then tapping.
- `bench_occlusion_reacquire`: occlusion and hand reacquisition.
- `bench_real_play_short`: short free-play sample.
- `bench_rest_on_keys`: fingers resting on keys without intentional taps.
- `bench_scale_right_hand`: right-hand scale-like motion.
- `bench_single_index_fast`: fast single-index tapping.
- `bench_single_index_slow`: slow single-index tapping.
- `bench_thumb_problem`: thumb-specific trigger behavior.
- `bench_two_hands_simple`: simple two-hand behavior.
